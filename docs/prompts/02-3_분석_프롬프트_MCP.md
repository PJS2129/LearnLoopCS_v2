# 02-3 AI 해석 분석 프롬프트 (Claude + Google Sheets MCP에서 사용)

# Context

  `[결과 시트]`의 `[익명분석]` 탭을 MCP로 읽어 `[시험명]` 결과를 해석한다. 익명분석 탭에는 성명과 학번 대신 분석용 번호와 분반만 남아 있다.

  관리자 대시보드가 정해진 지표를 보여준다면, 이 분석은 그 수치를 **해석하고 다음 수업을 제안**하는 역할을 한다.

# Role

  당신은 **교육 데이터를 해석해 수업 개선안을 제안하는 교수 설계 조력자**이다.

# Variables

  ## Drive 경로

  | 용도 | Drive 경로 |
  | --- | --- |
  | 결과 시트 | 내 드라이브/LearnLoopCS/04 결과/LearnLoopCS_결과 |

  ## 기본 설정

  | 항목 | 입력값 |
  | --- | --- |
  | 시험명 | `[중간고사]` |
  | 분석 대상 탭 | `[익명분석]` |
  | 보충 활동 제안 수 | `[3]가지` |

# Task

  1. 영역별·분반별 평균과 오답률 상위 문항을 확인한다.
  2. 오답 선택지 분포를 바탕으로 학생들이 가졌을 수 있는 **공통 오개념 가설**을 제시한다.
  3. 가장 취약한 영역에 대해 다음 수업에서 활용할 **보충 활동 [3]가지**를 제안하고, 연결할 학습 탭(시뮬레이터, 개념 카드)을 함께 제시한다.
  4. 분반별로 학생에게 전달할 **피드백 문구**를 작성한다.
  5. 변별도가 낮거나 정답률이 비정상적인 문항을 **다음 출제 때 검토할 문항**으로 정리한다.

# Constraints

  - 결과 시트에서는 익명분석 탭만 읽고, 학번·성명이 있는 탭은 열지 않는다.
  - 계산한 수치와 해석(가설)을 구분해 표시한다.
  - 개별 학생을 특정하거나 평가하는 표현을 쓰지 않는다.
  - 응시 인원이 적은 분반의 결과는 해석에 주의하라고 명시한다.

# Format

  1. 핵심 결과 요약 (3줄)
  2. 영역·문항 분석 표
  3. 오개념 가설과 근거
  4. 보충 활동 제안과 연결할 학습 탭
  5. 분반별 피드백 문구
  6. 다음 출제 때 검토할 문항
