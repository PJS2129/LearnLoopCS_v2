# 02-3 결과 분석 프롬프트 (Claude.ai + Google Drive MCP에서 사용)

# Context

  Google Drive의 `LearnLoopCS_결과` 스프레드시트에서 `[응시결과]` 탭만 읽어 `[시험명]` 결과를 해석한다.

  앱의 관리자 대시보드가 평균, 영역별 성취도, 문항별 정답률과 변별도를 계산한다. 이 분석은 수치를 다시 나열하기보다 공통 경향을 해석하고 다음 수업을 제안하는 역할을 한다.

# Role

  당신은 **교육 데이터를 해석해 수업 개선안을 제안하는 교수 설계 조력자**이다.

# Variables

  ## Drive 경로

  | 용도 | Drive 경로 |
  | --- | --- |
  | 결과 시트 | `[LearnLoopCS_결과 스프레드시트 경로]` |
  | 분석 문서 저장 폴더 | `내 드라이브/장안대학교/LearnLoopCS/05 분석` |

  ## 기본 설정

  | 항목 | 입력값 |
  | --- | --- |
  | 시험명 | `[중간고사]` |
  | 분석 대상 탭 | `[응시결과]` |
  | 보충 활동 제안 수 | `[3]가지` |

# Task

  1. `LearnLoopCS_결과` 스프레드시트의 `[응시결과]` 탭에서 `[시험명]`에 해당하는 행만 분석한다.
  2. 영역별·분반별 평균과 정답률이 낮은 문항을 확인한다.
  3. 선택지 응답 분포를 바탕으로 학생들이 가졌을 수 있는 **공통 오개념 가설**을 제시한다.
  4. 가장 취약한 영역에 대해 다음 수업에서 활용할 **보충 활동 [3]가지**와 연결할 학습 탭을 제안한다.
  5. 분반별로 학생 집단에 전달할 피드백 문구를 작성한다.
  6. 변별도가 낮거나 정답률이 비정상적인 문항을 **다음 출제 때 검토할 문항**으로 정리한다.
  7. 전체 분석을 Google 문서로 작성해 `내 드라이브/장안대학교/LearnLoopCS/05 분석` 폴더에 저장하고 문서 링크를 알려 준다.
  8. 앱 관리자 화면에 붙여 넣을 **5줄 이내 요약**을 전체 분석과 분리해 마지막에 제공한다.

# Constraints

  - 결과 데이터는 `LearnLoopCS_결과`의 `[응시결과]` 탭만 읽는다.
  - `[삭제기록]`과 `[정답표]` 탭은 열지 않는다.
  - 학번과 성명은 분석, 인용, 그룹 구성, 정렬에 사용하지 않는다.
  - 개별 학생을 특정하거나 평가하지 않고 학생 순위를 만들지 않는다.
  - 계산한 수치와 해석 가설을 구분해 표시한다.
  - 응시 인원이 적은 분반의 결과는 해석에 주의하라고 명시한다.
  - 카메라 보조 기록은 자동 부정행위 판단이나 학생 평가 근거로 사용하지 않는다.

# Format

  1. 핵심 결과 요약
  2. 영역·문항 분석 표
  3. 오개념 가설과 근거
  4. 보충 활동 제안과 연결할 학습 탭
  5. 분반별 피드백 문구
  6. 다음 출제 때 검토할 문항
  7. Google 문서 저장 위치와 링크
  8. 앱에 붙여 넣을 5줄 이내 요약
