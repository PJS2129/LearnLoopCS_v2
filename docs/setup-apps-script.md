# Apps Script 채점 및 정답표 서버 설정 가이드

이 문서는 구글 스프레드시트와 Apps Script를 연결하여 문항 확정(정답표 저장) 및 채점 서버를 구축하는 단계별 안내입니다.

---

## 1. 스프레드시트 준비 확인

1. Google Drive에서 결과 기록용 스프레드시트(`LearnLoopCS_결과`)를 엽니다.
2. 아래 3개 탭이 존재하는지 확인합니다. (없다면 탭 이름을 더블 클릭해 생성합니다)
   - `정답표`
   - `응시결과`
   - `삭제기록`

---

## 2. Apps Script 편집기 열기 및 코드 반영

1. 스프레드시트 상단 메뉴에서 **[확장 프로그램]** → **[Apps Script]**를 클릭합니다.
2. 기본으로 열리는 편집기 화면 좌측의 `Code.gs` 파일을 선택합니다.
3. 기존 코드를 모두 지우고, 프로젝트 저장소의 `apps-script/Code.gs` 전체 내용을 복사하여 붙여 넣습니다.
4. 상단 디스켓 모양의 **[저장]** 버튼(또는 단축키 `Ctrl + S`)을 눌러 저장합니다.
5. 상단 제목(기본: `제목 없는 프로젝트`)을 클릭하여 `LearnLoopCS_Server` 등으로 변경합니다.

---

## 3. 스크립트 속성 (Script Properties) 설정

보안상 관리자 이메일 목록과 Firebase Web API 키는 코드나 깃 저장소에 노출하지 않고, 구글 스크립트 속성에만 보관합니다.

1. Apps Script 화면 좌측 사이드바에서 톱니바퀴 모양의 **[프로젝트 설정]** 아이콘을 클릭합니다.
2. 화면을 아래로 스크롤하여 **[스크립트 속성]** 항목을 찾습니다.
3. **[스크립트 속성 추가]** 버튼을 눌러 다음 속성들을 등록합니다:

| 속성 (Property) | 값 (Value) 예시 및 설명 |
| --- | --- |
| `FIREBASE_API_KEY` | Firebase 프로젝트의 웹 API 키 (`.env.local`의 `VITE_FIREBASE_API_KEY` 값과 동일) |
| `ADMIN_EMAILS` | 관리자 이메일 목록을 쉼표(`,`)로 구분하여 입력 (예: `admin@example.ac.kr,prof@example.ac.kr`) |

> **중요 안내**: `ADMIN_EMAILS`의 실제 관리자 계정 주소는 반드시 이 스크립트 속성에만 입력해야 하며, 깃 저장소나 프론트엔드 코드에는 적지 않습니다.

4. 입력 후 하단의 **[스크립트 속성 저장]** 버튼을 누릅니다.

---

## 4. 웹 앱 배포 (Web App Deployment)

브라우저에서 정답표를 전송할 수 있도록 웹 앱으로 배포합니다.

1. Apps Script 우측 상단의 파란색 **[배포]** 버튼을 누르고 **[새 배포]**를 선택합니다.
2. 좌측 톱니바퀴 모양의 **[유형 선택]** 옆 아이콘을 클릭하고 **[웹 앱]**을 선택합니다.
3. 설정을 다음과 같이 지정합니다:
   - **설명**: `LearnLoopCS 정답표 및 채점 서버 v1`
   - **다음 사용자 권한으로 실행**: **나(사용자 이메일)** (스프레드시트 소유자 권한으로 실행)
   - **액세스 권한이 있는 사용자**: **모든 사용자** (Anyone)
     *(웹 앱 호출 시 관리자 ID 토큰을 내부에서 검증하므로, 네트워크 접근은 '모든 사용자'로 개방되어 있어야 브라우저에서 호출 가능합니다)*
4. 하단의 **[배포]** 버튼을 클릭합니다.
5. 처음 배포 시 **[액세스 승인]** 팝업이 뜰 수 있습니다:
   - 본인 Google 계정 선택
   - "Google에서 확인하지 않은 앱" 경고가 나타나면 좌측 하단의 **[고급]** 클릭
   - 하단의 **[LearnLoopCS_Server(으)로 이동(안전하지 않음)]** 클릭
   - 요청 권한(Google 스프레드시트 관리, 외부 서비스 연결) 확인 후 **[허용]** 클릭
6. 배포가 완료되면 화면에 **웹 앱 URL**이 나타납니다.
   - 형태: `https://script.google.com/macros/s/AKfycb.../exec`
   - 이 URL을 **복사**합니다.

## 4-1. Code.gs 코드 수정 후 기존 웹 앱 주소를 유지하는 재배포 방법

`Code.gs` 파일을 수정한 뒤 매번 [새 배포]를 누르면 웹 앱 주소(URL)가 바뀌어 프론트엔드의 `VITE_GAS_URL`을 다시 변경해야 합니다. **기존 주소를 그대로 유지**하면서 최신 코드를 반영하려면 아래 절차를 따릅니다:

1. Apps Script 편집기에서 코드 수정 후 **저장(Ctrl + S)**을 완료합니다.
2. 우측 상단의 파란색 **[배포]** 버튼을 클릭하고, **[배포 관리]**(Manage deployments)를 선택합니다.
3. 좌측 배포 목록에서 현재 활성화된 웹 앱 배포(활성 상태)를 선택합니다.
4. 우측 상단의 연필 모양 **[편집]**(Edit) 아이콘을 클릭합니다.
5. **[버전]** 드롭다운을 클릭하고 **[새 버전]**(New version)을 선택합니다.
   *(설명란에는 'v2 - 4-2단계 채점 및 응시결과 기록 반영' 등 메모 입력)*
6. 하단의 **[배포]** 버튼을 누릅니다.
7. 웹 앱 URL이 바뀌지 않고 기존 URL 그대로 최신 서버 로직이 즉시 반영됩니다.

## 4-2. 제출 및 서버 오류 시 Apps Script [실행 로그] 확인 방법

학생이 답안을 제출할 때 "답안 전송 오류"가 발생하거나 정답표 확정 시 문제가 생기면, Google Apps Script의 **[실행]**(Executions) 메뉴에서 서버 측의 실제 에러 원인을 실시간으로 확인할 수 있습니다:

1. 구글 스프레드시트 상단 메뉴에서 **[확장 프로그램] → [Apps Script]**를 클릭하여 편집기를 엽니다.
2. 좌측 사이드바 메뉴에서 재생 버튼 모양(▶)의 **[실행]**(Executions) 아이콘을 클릭합니다.
3. 최근에 호출된 웹 앱 요청(`doPost`, `doGet`) 목록이 시간순으로 표시됩니다.
4. 상태가 **실패**(Failed)로 빨갛게 표시된 항목이나 최근 실행 항목을 클릭합니다.
5. 화면 하단에 열리는 실행 로그 창에서 오류 원인을 확인합니다:
   - **관리자 권한 오류**: `관리자 권한이 없는 계정입니다: xxx@gmail.com`이 나타난다면, 웹 앱이 아직 구버전 코드로 실행 중이므로 위 4-1절 안내에 따라 **[배포 관리] → [편집] → 버전: [새 버전]**으로 재배포해야 합니다.
   - **정답표 중복 오류**: `정답표 중복 오류: [midterm-2026] 정답표에 중복된 문항 번호가 존재합니다 (1번)`이 나타난다면, 정답표 시트의 1번 문항 행이 2개 이상이므로 관리자 화면에서 [문항 점검 완료]를 다시 눌러 덮어쓰거나 수동 정리합니다.
   - **세션 누락 오류**: `응시 세션 문서가 존재하지 않습니다`가 나타난다면 학생이 정식으로 코드를 입력하고 입장하지 않은 상태입니다.

## 5. 로컬 개발 환경 및 Vercel 환경 변수 등록

### (1) 로컬 개발 환경 (`.env.local`)
1. 프로젝트 루트의 `.env.local` 파일을 엽니다.
2. 복사한 웹 앱 URL을 붙여 넣습니다:
   ```env
   VITE_GAS_URL=https://script.google.com/macros/s/AKfycb.../exec
   ```
3. 개발 서버가 실행 중이라면 터미널에서 `npm run dev`를 재시작하여 환경 변수를 반영합니다.

### (2) Vercel 프로덕션 배포 등록
1. [Vercel 대시보드](https://vercel.com/) 접속 → 해당 프로젝트 선택
2. **Settings** → **Environment Variables** 메뉴로 이동
3. 환경 변수 추가:
   - Key: `VITE_GAS_URL`
   - Value: `https://script.google.com/macros/s/AKfycb.../exec`
4. **Save**를 누른 뒤, 최신 커밋을 다시 배포(Redeploy)하거나 git push하여 변경 사항을 반영합니다.

## 6. 동작 확인 및 점검 절차

1. 관리자 계정으로 로그인한 상태에서 상단 메뉴의 **[관리자]** 탭 → **[문항 관리]**로 이동합니다.
2. **[문항 JSON 가져오기]**를 눌러 샘플 문항(`docs/samples/exam-sample.json`)을 가져옵니다.
3. 형식 검사 오류가 0건인지 확인한 후 활성화된 **[점검 완료]** 버튼을 누릅니다.
4. 모달에서 시험ID(예: `midterm-2026`)를 확인하고 **[점검 완료 및 확정 저장]**을 클릭합니다.
5. 구글 시트의 `[정답표]` 탭에 10개 열로 문항별 정답 및 해설이 등록되었는지 확인합니다.
6. Firebase 콘솔의 Firestore `exams/{examId}` 및 `exams/{examId}/questions/{no}` 문서에 문항 데이터가 저장되었는지 확인합니다.
