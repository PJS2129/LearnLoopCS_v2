# 명세 4. 관리자 탭

> Task 9. 공통 규칙은 프로젝트 루트의 AGENTS.md를 따른다.

## 9. 관리자 탭

  관리자 탭은 어두운 Navy 사이드 메뉴와 Gold 강조를 사용해 학생 화면과 구분한다. 메뉴는 다음과 같다.

  ### 9-1. 문항 관리 (AI 출제 결과 가져오기)

    - 교수자가 MCP 출제 프롬프트로 받은 **문항 JSON 파일을 업로드**하거나 붙여 넣어 가져온다.
    - 가져오기 전에 형식을 검사한다: 문항 수, 선택지 수, 정답 범위, 영역 태그, 난이도, 근거.
    - **검토 화면**: 전체 문항을 한 화면에 표로 보여준다 (번호, 질문, 선택지, 정답, 영역, 난이도, 근거 자료·페이지, 해설). 문항별로 바로 수정할 수 있다.
    - 화면 위에 영역별·난이도별 문항 수 요약과 태깅 규칙 위반 표시를 둔다.
    - 교수자가 **[점검 완료]**를 눌러야 문항이 확정된다. 확정 시 정답은 `[정답표]` 탭으로, 정답을 뺀 문항은 Firestore로 보낸다.
    - 점검 완료 전에는 **[시험 열기]** 버튼을 비활성화한다.

  ### 9-2. 시험 운영

    - 시험 상태 전환(준비 중 → 시험 열기 → 시험 닫기), 시험 코드 생성·재발급.
    - 실시간 응시 현황: 입장 인원, 응시 중 인원, 제출 완료 인원, 학생별 남은 시간.

  ### 9-3. 시험 미리보기

    - 실제 학생의 응시 안내와 시험지 화면을 읽기 전용으로 미리 본다.
    - 미리보기에서는 타이머, 카메라, 세션 생성, 제출과 기록이 동작하지 않는다.
    - 관리자만 정답 표시를 켜고 끌 수 있다.

  ### 9-4. 성적과 분석

    | 화면 | 내용 |
    | --- | --- |
    | 한눈에 보기 | 응시 인원, 평균, 표준편차·분산, 최고·최저 점수, 평균 정답률 기준 시험 난이도 |
    | 분포 | 10점 구간 점수 분포, 정답률 기준 문항 난이도 분포 |
    | 오답 TOP 5 | 문항번호, 영역, 핵심 개념, 정답률, 가장 많이 선택한 오답과 비율 |
    | 영역 분석 | 5개 영역별 평균 성취도와 분반 비교 |
    | 전체 성적표 | 학생별 총점, 5개 영역 점수, 제출 방식, 카메라 이탈 보조 기록 |
    | AI 분석 요약 | Claude.ai와 Google Drive MCP로 만든 분석을 교수자가 검토한 뒤 요약과 문서 링크를 게시 |

    - 응시 인원이 10명 미만이면 오답 TOP 5 위에 해석 주의 안내를 표시한다.
    - 앱과 Apps Script에서 AI API를 호출하지 않는다.
    - 분석 요약은 관리자 전용 Script Properties에 시험별로 저장하며, 교수자 검토 확인 후에만 게시한다.
    - 화면에는 "AI가 작성한 참고 의견이며 교수자가 검토했습니다"라고 표시한다.

  ### 9-5. 성적 공개

    - 시험 개방과 성적 공개는 **서로 다른 승인 단계**로 관리한다.
    - 공개 범위(총점, 영역별 성취도, 문항별 정오)를 선택하고 미리보기한 뒤 **[성적 공개]**를 누른다.

  ### 9-6. 학습 콘텐츠 관리

    - `[학습 탭 슬롯 표]`의 탭을 추가·수정·숨김 처리하고 콘텐츠 파일이나 주소를 등록한다.
    - 등록 전 미리보기로 콘텐츠가 정상적으로 표시되는지 확인한다.
