# 명세 2. 학습 탭과 학습 콘텐츠

> Task 2~6. 공통 규칙은 프로젝트 루트의 AGENTS.md를 따른다.

## 2. 학습 탭 슬롯 구조

  ### 슬롯 유형

    | 유형 | 콘텐츠 형식 | 다른 과목 적용 |
    | --- | --- | --- |
    | 시뮬레이터 | HTML 한 파일 또는 주소 | 채팅형 AI로 과목별 시뮬레이터를 만들어 교체 |
    | 개념 카드·연습 문제 | JSON 데이터 파일 | 출제 프롬프트로 강의자료에서 생성해 교체 |
    | 외부 학습 도구 | 외부 주소 | 주소만 등록 |

    - 시뮬레이터와 외부 도구는 `iframe`(sandbox)으로 불러와 플랫폼의 로그인 정보와 데이터에 접근할 수 없게 한다.
    - 새 학습 탭을 추가하거나 교체할 때 **플랫폼 코드를 수정하지 않아도** 되어야 한다.
    - 내용이 준비되지 않은 탭은 `준비 중` 안내 카드로 표시한다.

  ### 활동 신호 규약

    - 시뮬레이터는 `postMessage`로 `{ type: "activity", tab, activity, detail, duration }` 형식의 신호를 보낸다.
    - 플랫폼은 이 신호를 받아 학습 이력에 저장한다. 신호를 보내지 않는 콘텐츠는 탭 열람 시간만 기록한다.


## 3. 학습 콘텐츠 A: 알고리즘 인터랙티브 스튜디오 (`content/algorithm.html`)

  탐색·정렬 알고리즘이 데이터를 어떤 순서와 이유로 비교·이동하는지 막대 그래프로 관찰하는 단일 HTML 시뮬레이터를 만든다.

  ### 화면 구성

    - **상단 바**: 반투명 흰 배경에 창 버튼 모양의 점 세 개(빨강·노랑·초록)와 제목 `알고리즘 인터랙티브 스튜디오`를 두고, 오른쪽에 **[탐색 알고리즘 | 정렬 알고리즘]** 세그먼트 컨트롤을 둔다.
    - **설정 카드(왼쪽, 넓은 화면에서 7/12)**: 알고리즘 선택 드롭다운, 찾을 숫자 입력(1~100, 탐색 모드에서만 표시), 데이터 개수 슬라이더(`[5~60]`, 기본 `[20]`, 현재 값 배지), 속도 슬라이더(왼쪽 느림 → 오른쪽 빠름), **[데이터 재생성]**과 **[시뮬레이션 시작]** 버튼.
    - **분석 카드(오른쪽, 5/12)**: 알고리즘 이름, 한 줄 설명, 시간 복잡도 배지(예: `O(n log n)`), 효율성 요약 박스.
    - **시각화 카드(하단)**: 제목과 상태 표시(`READY`·`RUNNING`·`PAUSED`·`COMPLETED`, 상태마다 색 변경), 범례 바, 막대 영역, 그 아래 **실시간 실행 가이드** 말풍선.
    - 좁은 화면에서는 설정·분석·시각화 카드를 세로로 쌓는다.

  ### 막대와 색 규칙

    - 데이터 값은 12~96 범위의 무작위 정수로 만들고, 막대 높이를 값에 비례시키며 막대 안에 숫자를 표시한다.
    - 숫자 크기는 데이터 개수에 맞춰 `11~26px` 사이에서 자동 조절해 항상 읽을 수 있게 한다.
    - 상태 색: 대기 인디고, 비교·선택 노랑(살짝 맥동), 교환·이동 빨강, 피벗 보라, 정렬 완료 초록, 탐색에서 제외된 범위 회색.
    - 범례에는 `피벗(기준값)`처럼 용어를 쉬운 말과 함께 표기한다.

  ### 알고리즘 동작

    | 알고리즘 | 동작과 설명 기준 |
    | --- | --- |
    | 선형 탐색 | 앞에서부터 하나씩 목표값과 대조하고, 확인한 막대는 회색으로 바꾼다. 찾지 못하면 그 사실을 안내한다. |
    | 이진 탐색 | 먼저 오름차순 정렬을 보여준 뒤 탐색한다. 범위 밖 막대는 회색, 범위 안은 연한 인디고, 중앙값은 노랑으로 표시한다. |
    | 버블 정렬 | 인접한 두 값을 비교·교환하고, 한 회차가 끝날 때마다 오른쪽 끝 막대를 정렬 완료로 표시한다. |
    | 선택 정렬 | 남은 구역에서 최솟값 후보를 빨강으로 추적하고, 탐색이 끝나면 현재 자리와 교환한다. |
    | 삽입 정렬 | 현재 원소를 인접 교환으로 한 칸씩 왼쪽으로 옮겨, 끼워 넣는 과정을 눈으로 따라갈 수 있게 한다. |
    | 퀵 정렬 | 구간의 중앙 위치 원소를 피벗으로 고르고 구간 끝으로 옮긴 뒤, 작은 값을 왼쪽에 모으고 피벗을 경계에 놓는다. |

    - 각 단계마다 실행 가이드에 "무엇을 비교하고 왜 바꾸는지"를 한 문장으로 표시한다.
    - 분석 카드에는 각 알고리즘의 시간 복잡도와 특징(예: 삽입 정렬은 거의 정렬된 데이터에서 빠름)을 표시한다.

  ### 실행 제어

    - **[시뮬레이션 시작]**은 실행 중 빨간 **[시뮬레이션 중단]**으로 바뀐다.
    - 중단 여부는 모든 대기 직후와 재귀 진입 시 확인해, 중단 후 이전 실행이 화면을 바꾸지 않게 한다.
    - 실행 중에는 모드 전환과 데이터 재생성을 막는다.
    - 실행을 시작·완료할 때 활동 신호(`algorithm`, 알고리즘 이름, 소요 시간)를 보낸다.


## 4. 학습 콘텐츠 B: 논리회로 랩 (`content/logic.html`)

  학생이 논리 게이트를 직접 배치하고 선으로 연결해, 입력을 바꿀 때 출력이 어떻게 변하는지 진리표와 함께 확인하는 단일 HTML 시뮬레이터를 만든다.

  ### 화면 구성

    - **배경**: 짙은 남색(`#0F172A`) 캔버스에 28px 간격의 점 격자를 깐다.
    - **상단 툴바**: 왼쪽에 하늘색으로 빛나는 점과 `LOGIC LAB` 제목, 이어서 두 그룹의 버튼을 둔다.
      - `I/O`: **SWITCH**(초록), **LED**(주황)
      - `GATES`: AND, OR, XOR, NOT, NAND, NOR, XNOR
    - 툴바 오른쪽: 현재 조작 안내 문구, **[회로 설명]** 버튼, 빨간 **[CLEAR]** 버튼.

  ### 부품과 조작

    - 게이트는 **IEEE 표준 기호**(SVG)로 그리고 아래에 이름 라벨을 붙인다.
    - SWITCH는 클릭하면 켜짐/꺼짐이 바뀌는 토글, LED는 입력이 1이면 노랗게 빛나는 전구로 표현한다.
    - 부품은 드래그해서 옮기고, 마우스를 올리면 오른쪽 위에 빨간 **×** 삭제 버튼이 나타난다.
    - 입력 단자는 왼쪽(1~2개), 출력 단자는 오른쪽에 둔다. 출력 단자와 입력 단자를 차례로 누르면 곡선 전선이 연결된다.
    - 연결을 기다리는 단자는 맥동하고, 안내 문구가 "연결할 입력 단자를 클릭하세요"처럼 바뀐다.
    - 하나의 입력 단자에는 전선 하나만 연결되며, 새로 연결하면 이전 전선을 대체한다.
    - 마우스와 터치를 모두 지원한다(포인터 이벤트).

  ### 신호와 표시

    - 신호가 1인 전선은 주황색으로 굵어지며 빛나고, 출력이 1인 게이트는 테두리가 주황색으로 바뀐다.
    - 입력이 바뀌면 회로 전체에 신호를 다시 전달한다. 되먹임 회로에서도 멈추지 않도록 반복 횟수를 제한한다.
    - 처음 열면 SWITCH 두 개 → XOR → LED의 **예시 회로**를 미리 배치한다.

  ### 회로 설명 패널

    **[회로 설명]**을 누르면 오른쪽에서 패널이 미끄러져 나와 실시간으로 갱신된다.

    - **전체 요약 카드**: 각 SWITCH의 현재 값(SW1: 1 …)과 각 LED의 상태(ON/OFF)
    - **게이트별 카드**: 게이트 이름과 한글 명칭(예: 배타적 논리합), 한 줄 설명, `입력 → 출력` 값, 진리표
    - 진리표에서는 **현재 입력에 해당하는 행을 강조**해, 지금 회로가 진리표의 어느 줄에 있는지 보여준다.
    - 게이트가 없으면 "상단 메뉴에서 게이트를 추가해 보세요" 안내를 표시한다.
    - 회로를 바꾸거나 설명 패널을 열 때 활동 신호(`logic`, 사용한 게이트 종류)를 보낸다.


## 5. 학습 콘텐츠 C: 개념 카드·연습 문제

  - 하나의 공통 화면으로 구현하고, `content/[영역].json`만 바꾸면 다른 내용이 표시되게 한다.
  - **개념 카드**: 개념명, 쉬운 설명, 예시, 근거 자료를 카드 그리드로 보여준다. 카드를 누르면 예시가 펼쳐진다.
  - **연습 문제**: 한 화면에 한 문제씩 풀고, 제출하면 바로 정답 여부와 해설을 보여준다. 결과는 학습 이력에 기록하되 시험 점수와 섞지 않는다.


## 6. 학습 이력과 맞춤 복습

  - **학습 이력 탭**: 영역별 학습 시간 막대, 최근 활동 목록(시각, 탭, 활동), 연습 문제 정답률을 보여준다.
  - **맞춤 복습**: 성적이 공개된 후 영역별 성취도가 가장 낮은 영역을 찾아 해당 학습 탭으로 가는 **[이 영역 복습하기]** 버튼을 보여준다.
  - 추천 문구는 점수를 평가하는 말이 아니라 다음 학습 행동을 안내하는 말로 작성한다.
