# 명세 1. 공통 셸과 로그인

> Task 1. 공통 규칙은 프로젝트 루트의 AGENTS.md를 따른다.

## 1. 공통 셸과 로그인

  ### 셸 헤더와 탭 바

    - 상단 고정 헤더: 왼쪽에 `[앱 이름]`과 과목명, 오른쪽에 로그인한 사용자(성명·학번)와 로그아웃 버튼을 둔다.
    - 헤더 아래 탭 바: `[학습 탭 슬롯 표]`의 학습 탭 → **학습 이력** → **시험** → **관리자** 순서로 표시한다.
    - 학습 탭은 슬롯 표(`learning-tabs.json`)를 읽어 **자동으로 생성**하며, 탭 이름이나 순서를 코드에 직접 적지 않는다.
    - **관리자** 탭은 금색 방패 아이콘과 함께 `[관리자 계정]`으로 로그인한 경우에만 표시한다.
    - 모바일에서는 탭 바를 가로 스크롤 가능한 칩 형태로 바꾼다.

  ### 로그인과 학생 등록

    - 첫 화면은 `[앱 이름]` 로고, 한 줄 소개, **[Google 계정으로 시작하기]** 버튼만 있는 간결한 화면으로 구성한다.
    - 최초 로그인 시 **학번·성명·분반**을 한 번 등록하는 모달을 띄운다. 학번은 앞자리 0이 사라지지 않도록 문자열로 저장한다.
    - 등록한 정보는 시험지와 결과에 자동으로 사용하며, 학생이 시험 중에 다시 입력하지 않는다.

  ### 권한

    - 학생은 **본인의 기록만** 조회할 수 있도록 Firestore 보안 규칙을 작성한다.
    - 관리자 권한은 화면 숨김만으로 처리하지 않고 보안 규칙과 서버에서 다시 확인한다.
