# 검증 체크리스트

> Verification. 공통 규칙은 프로젝트 루트의 AGENTS.md를 따른다.

## 권한과 문항

  - [ ] 학생 계정에는 관리자 탭이 보이지 않고, 다른 학생 기록에 접근할 수 없는가?
  - [ ] 문항 JSON 가져오기에서 형식 오류와 태깅 규칙 위반이 표시되는가?
  - [ ] 점검 완료 전에는 [시험 열기]가 비활성화되는가?
  - [ ] 정답이 브라우저 코드와 Firestore에 포함되지 않는가?

## 학습 탭

  - [ ] `public/learning-tabs.json`만 수정해 학습 탭을 추가·교체할 수 있는가?
  - [ ] 알고리즘 6종의 동작, 색 변화, 실행 가이드 문장이 일치하는가?
  - [ ] 실행 중 중단 후 다시 시작해도 이전 실행의 색이나 동작이 남지 않는가?
  - [ ] 논리 게이트 7종의 출력과 진리표 강조 행이 실제 입력과 일치하는가?
  - [ ] 터치 기기에서 게이트 이동과 전선 연결이 되는가?
  - [ ] 활동 신호가 학습 이력에 기록되는가?

## 응시와 채점

  - [ ] 시험 코드 없이 입장할 수 없고, 제출 후 재응시와 수정이 막히는가?
  - [ ] 새로고침 후에도 종료 시각이 유지되고, 경고와 자동 제출이 동작하는가?
  - [ ] OMR 번호판의 상태와 실제 응답·깃발 표시가 일치하는가?
  - [ ] 시트의 총점·영역별 성취도가 직접 계산한 값과 일치하는가?
  - [ ] 응시결과 시트가 1~57열 구조를 유지하고 제출 방식이 57열에 기록되는가?

## 공개와 분석

  - [ ] 성적 공개 전에는 점수가 보이지 않고, 공개 후 본인 결과만 보이는가?
  - [ ] 평균·표준편차·점수 분포·영역 평균·오답 TOP 5가 시트 데이터와 일치하는가?
  - [ ] 학생 계정의 분석 데이터 및 AI 분석 요약 요청이 서버에서 거부되는가?
  - [ ] 맞춤 복습 추천이 실제 최저 영역과 일치하는가?

## 보조 기능과 화면

  - [ ] 탭 이탈과 카메라 화면 이탈의 횟수·시간이 기록되는가?
  - [ ] 카메라 영상이 네트워크로 전송되지 않는가?
  - [ ] 데스크톱·태블릿·스마트폰에서 화면이 잘리지 않고 가로 스크롤이 없는가?

마지막에는 **실제로 구현하고 검증한 기능**과 **아직 구현·검증하지 못한 기능**을 구분해 보고한다.
