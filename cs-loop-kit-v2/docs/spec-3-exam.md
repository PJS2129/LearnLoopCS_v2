# 명세 3. 시험 탭과 서버 채점

> Task 7~8. 공통 규칙은 프로젝트 루트의 AGENTS.md를 따른다.

## 7. 시험 탭

  ### 시험 상태별 화면

    | 상태 | 학생에게 보이는 화면 |
    | --- | --- |
    | 준비 중 | 잠금 아이콘과 "아직 시험이 열리지 않았습니다" 안내, 시험명·일시 |
    | 시험 열림 | 시험 코드 입력 → 응시 안내·동의 화면 → 시험지 |
    | 제출 완료 | 접수 확인 화면 (점수 없음) |
    | 성적 공개 | 내 결과 화면 (총점, 영역별 성취도, 맞춤 복습) |

  ### 입장과 동의

    - 시험이 열리면 교수자가 배포한 **시험 코드**를 입력해야 입장할 수 있다.
    - 응시 안내 화면에 제한시간, 문항 수, 제출 후 수정 불가, 보조 기능(탭 이탈 기록, 카메라 화면 이탈 알림)과 **기록되는 항목**을 안내하고 동의를 받는다.
    - **[시험 시작]**을 누르는 시점의 서버 시각을 입장 시각으로 기록한다.

  ### 시험지 화면

    - **페이지**: 연회색 배경 위에 가운데 정렬된 시험지(최대 폭 약 900px).
    - **시험지 헤더 카드**: 상단에 두꺼운 Navy 선, 학과 배지, 큰 시험 제목, `[시험 일시] | [과목명] (총 [총 문항 수]문항 / 문항당 [문항당 배점]점 / 100점 만점)` 부제, 응시자 정보(학번·성명, 읽기 전용), 노란 유의사항 박스.
    - **상단 고정 바**: 스크롤해도 보이도록 남은 시간(`49:59`)과 진행 상태(`25 / 40 완료`)를 고정한다. 모두 답하면 진행 상태가 초록색으로 바뀐다.
    - **문항 카드**: Navy 번호 배지, 질문, 오른쪽 위 배점 태그, 선택지 4개. 선택지는 카드 전체 폭을 누를 수 있는 버튼형이며 앞에 동그란 번호 배지를 둔다.
    - **선택 상태**: 선택한 선택지는 연한 파랑 배경, 파란 테두리, 채워진 번호 배지로 표시한다.
    - **표시(깃발)**: 문항 카드 오른쪽 위의 깃발 버튼으로 "다시 볼 문항"을 표시한다.
    - **제출 영역**: 마지막에 "모든 답안을 꼼꼼하게 검토하셨나요?" 문구와 큰 Navy **[시험지 최종 제출하기]** 버튼.

  ### OMR 네비게이션

    - 넓은 화면에서는 오른쪽에 고정된 번호판, 모바일에서는 하단 **[답안 현황]** 버튼으로 펼치는 시트로 보여준다.
    - 번호 칸 상태: 푼 문항 파랑, 표시한 문항 노랑(깃발 아이콘), 안 푼 문항 회색 테두리.
    - 번호를 누르면 해당 문항으로 부드럽게 이동한다.

  ### 타이머와 자동 제출

    - 종료 시각은 `입장 시각 + [제한시간]`으로 계산하며, 새로고침하거나 탭이 비활성화되어도 바뀌지 않는다.
    - `[종료 경고]` 시점에 타이머 색을 바꾸고 상단 안내 띠를 띄운다. 마지막 1분에는 타이머가 깜빡인다.
    - 종료 시각이 되면 선택한 답안을 자동 제출하고 시험지를 잠근다. 선택하지 않은 문항은 미응답으로 처리한다.

  ### 미답변 확인과 제출

    - 제출 버튼을 누르면 풀지 않은 문항을 찾아 카드를 빨간 테두리(맥동)로 표시하고, **미답변 확인 모달**에 누락 번호를 빨간 배지로 나열한다.
    - 배지를 누르면 모달이 닫히고 그 문항으로 이동한다. 모달에는 **[문제 풀러가기]**와 **[그대로 제출하기]**를 둔다.
    - 제출 중에는 회전 로딩 모달("답안을 제출하고 있습니다")을 띄운다.
    - 전송에 실패하면 답안을 브라우저에 임시 보관하고 재전송하며, 서버의 저장 성공 응답을 받기 전에는 접수 완료로 표시하지 않는다.

  ### 접수 확인 화면

    - 시험지를 숨기고 가운데에 큰 초록 체크 원, 상단에 Navy→파랑→Gold 그라데이션 선이 있는 카드를 표시한다.
    - 응시 과목, 시험 일시, 제출 학생, 제출 시각, `제출 완료 (수정 불가)` 잠금 배지를 표로 보여준다.
    - **점수는 표시하지 않는다.** "성적은 교수자가 공개한 뒤 시험 탭에서 확인할 수 있습니다"라고 안내한다.

  ### 응시 집중을 돕는 보조 기능

    - **탭 이탈 기록**: `visibilitychange`로 시험 화면을 벗어난 횟수와 누적 시간을 기록하고, 돌아오면 안내 모달을 보여준다.
    - **카메라 화면 이탈 알림**: 동의한 경우에만 카메라를 켠다.
      - 카메라 영상은 학생 기기 안에서 **얼굴이 화면을 벗어났는지 판별하는 데만** 사용한다.
      - 화면 구석에 작은 미리보기와 "카메라 사용 중" 표시를 두어 학생이 항상 알 수 있게 한다.
      - 얼굴이 일정 시간 감지되지 않으면 알림을 띄우고 **이탈 횟수와 시간만** 기록한다.
      - 영상과 이미지는 **서버로 전송하거나 저장하지 않으며**, 얼굴로 본인 여부를 판별하지 않는다.
      - 동의하지 않으면 `[카메라 미동의 시 처리]`를 따른다.
    - 보조 기록만으로 부정행위를 **자동 판정하지 않으며**, 교수자의 확인 자료로만 사용한다.

  ### 내 결과 화면 (성적 공개 후)

    - 총점, 영역별 성취도 막대(영역별 문항 수 함께 표시), 공개 범위에 따른 문항별 정오를 보여준다.
    - 가장 낮은 영역에 대해 **[이 영역 복습하기]** 버튼으로 학습 탭을 연결한다.


## 8. 서버 채점과 기록

  - 문항(정답 제외)은 Firestore에 저장하고, 시험이 열린 상태에서 시험 코드를 확인한 학생만 읽을 수 있게 한다.
  - 정답은 시트의 `[정답표]` 탭에만 보관하고 **브라우저 코드와 Firestore에 넣지 않는다.**
  - 학생 화면은 **응시 ID, 답안, 보조 기록**만 전송한다. Apps Script가 학생의 로그인 토큰 또는 시험 세션을 확인한 뒤 정답표와 대조해 채점한다. 토큰 검증이 어려우면 대체 방식을 쓰고 그 한계를 보고한다.
  - 결과는 `[응시결과]` 탭에 응시마다 새 행으로 추가한다 (`[총 문항 수]` 40 기준).

  | 열 | 내용 |
  | --- | --- |
  | 1~5 | 제출 시각, 응시 ID, 학번, 성명, 분반 |
  | 6~45 | 1~40번 응답 (미응답은 `미응답`) |
  | 46~47 | 틀린 문항 번호, 총점 |
  | 48~52 | 5개 영역별 성취도(%) |
  | 53~54 | 탭 이탈 횟수, 탭 이탈 누적 시간 |
  | 55~56 | 카메라 화면 이탈 횟수, 이탈 누적 시간 (미동의 시 `미동의`) |
  | 57 | 제출 방식 (직접/자동) |

  - `[총 문항 수]`를 바꾸면 응답 열과 이후 열 번호를 함께 조정한다.
  - 성적 공개 시 학생별 총점과 영역별 성취도를 Firestore의 본인 결과 문서로 옮긴다.
  - 분석용으로 성명·학번을 지운 `[익명분석]` 탭을 함께 갱신한다.
